Resumen

Resumen

Para planificar la integración de sus switches Huawei con Illumio necesitamos ver qué exportan realmente. Este kit le indica cómo reunir esa evidencia con tres elementos: una captura de red corta, la salida de algunos comandos display y un cuestionario breve. No se instala ni se modifica nada en los switches, salvo un ajuste opcional descrito en la Parte 1.

Qué recolecta y a dónde va

Qué responde la evidencia

  • Si los switches exportan flujos IP (direcciones y puertos IPv4/IPv6) o solo flujos de capa 2 (MAC/VLAN).
  • Qué versión de NetStream usa cada switch y si NetStream para IPv6 está configurado.
  • Si hay una tasa de muestreo configurada y si los flujos la informan.
  • Qué tarjetas de línea o miembros de stack exportan, el refresco de plantillas y el puerto UDP de origen.
  • Si el reloj, la zona horaria y el NTP de cada equipo son correctos.
  • El modelo y la versión de software exactos de cada switch.

Qué necesita

  • Un host Linux que reciba los paquetes NetStream (el colector o cualquier host que vea el tráfico), con tcpdump.
  • Acceso de lectura a cada switch (consola o SSH) para ejecutar comandos display.
  • Aproximadamente una hora en total. La captura corre mientras reúne la salida de los comandos.
Fuentes

  2. Huawei CloudEngine 12800 — NetStream configuration commands — support.huawei.com/enterprise/en/doc/EDOC1100138131/3a962da5/netstream-configuration-commands
Captura

Parte 1: Capture el tráfico NetStream

El switch envía NetStream como paquetes UDP hacia su colector. Registrar esos paquetes en el host receptor nos muestra exactamente qué exporta cada switch. Los paquetes contienen solo resúmenes de flujo (direcciones, puertos, protocolo y contadores), no el contenido de su tráfico.

1

Anote los valores que usará

La interfaz de red del host receptor que ve los paquetes NetStream y la dirección IP de gestión o de origen de cada switch. Ejecute date -u en el host y anote el resultado: lo comparamos con el reloj del switch.

2

Inicie la captura

Use un archivo por switch, o un archivo para todos (vea el segundo comando). Detenga con Ctrl+C, o use la forma con timeout para que se detenga sola.

HOST DE CAPTURA (LINUX)
# Un switch. Reemplace los valores entre corchetes angulares.
sudo tcpdump -i <interfaz> -s 0 -nn -w netstream.pcap udp and host <ip-del-switch>

# Varios switches en un archivo; se detiene sola a los 40 minutos (2400 s).
sudo timeout -s INT 2400 tcpdump -i <interfaz> -s 0 -nn -w netstream.pcap \
  udp and '(host <ip-switch-1> or host <ip-switch-2>)'
3

Asegure que la captura incluya las plantillas

Los switches con versión 9 describen sus registros en una plantilla que se envía solo de vez en cuando. Sin ella los registros no se pueden leer. Elija una opción.

OpciónQué hacer
A. Captura más larga (sin cambios en el switch)Capture durante 40 minutos, de modo que cubra el refresco de plantillas por defecto de 30 minutos1.
B. Refresco más corto (si su proceso de cambios lo permite)Configure el refresco de plantillas en 1 minuto durante la captura, capture 15 minutos y luego restaure su valor anterior. Serie S y AR: ip netstream export template timeout-rate 1. CE: netstream export ip template timeout-rate 1. Use ? para confirmar el nombre del comando en su versión de software.
C. Captura al iniciar la exportaciónSi habilita o reinicia la exportación NetStream en una ventana de mantenimiento, inicie la captura justo antes. Los switches envían sus plantillas cuando comienza la exportación.
4

Verifique el archivo

Liste los primeros paquetes. Debe ver paquetes UDP desde la IP del switch hacia su colector. Muchos switches Huawei envían desde el puerto UDP de origen 400001. Si el archivo está vacío, revise el nombre de la interfaz, la IP del switch y cualquier firewall entre el switch y el host.

HOST DE CAPTURA (LINUX)
tcpdump -nn -r netstream.pcap -c 5
¿No tiene acceso al host receptor?
Use espejado de puertos (SPAN) en el puerto del switch que se conecta al colector y envíe el tráfico espejado a un host Linux que ejecute el mismo comando tcpdump sobre la interfaz de espejo. Use su procedimiento estándar de espejado de puertos.
Fuentes
  1. Módulo YANG de NetStream de Huawei (refresco de plantillas 30 min, puerto de origen 40000) — netconfcentral.org/modules/huawei-netstream/2019-06-27
  2. Manual de tcpdump — tcpdump.org/manpages/tcpdump.1.html
Comandos

Parte 2: Reúna la información de los switches

Ejecute los comandos siguientes en cada switch mientras corre la captura. Guarde la salida de cada switch en un archivo de texto (por ejemplo con el registro de sesión de su terminal). Si un comando no se reconoce en su versión de software, escriba el inicio del comando seguido de ?, use la opción más cercana y continúe con el siguiente.

2.1 Modelo, software y tarjetas de línea

CLI DEL SWITCH
screen-length 0 temporary
display version
display device

2.2 Reloj, zona horaria y NTP

Ejecute display clock en el momento en que ejecuta date -u en el host de captura, o anote ambas horas. Use el comando NTP que acepte su software: ntp-service en serie S y AR, ntp en CE.

CLI DEL SWITCH
display clock
display ntp-service status
display ntp-service sessions
# Software CE:
display ntp status
display ntp sessions
display current-configuration | include clock
display current-configuration | include ntp

2.3 Configuración de NetStream

CLI DEL SWITCH
display current-configuration | include netstream
display current-configuration | include sampler

Las líneas de interfaz (por ejemplo ip netstream inbound o netstream inbound ip) aparecen bajo su interfaz en la configuración completa. Si puede compartir la configuración completa, agregue la salida de display current-configuration. Si no, ejecute display this dentro de cada interfaz que tenga NetStream e incluya el nombre de la interfaz.

2.4 Estado y estadísticas de NetStream

Liste los comandos display de NetStream de su versión, ejecute los de estadísticas y de caché de flujos y agregue su salida.

CLI DEL SWITCH
display ip netstream ?
# Software CE:
display netstream ?

Entrega

Parte 4: Nombre y envíe los archivos

Nombres de archivo

Use este patrón, en minúsculas y sin espacios: <sitio>_<switch>_<contenido>_<aaaammdd>.<ext>. Los nombres siguientes son ejemplos.

Archivo (nombres de ejemplo)Contenido
sitio-ejemplo_tor-sw-example-01_netstream_20261105.pcapCaptura de la Parte 1
sitio-ejemplo_tor-sw-example-01_display_20261105.txtSalida de comandos de la Parte 2
sitio-ejemplo_cuestionario_20261105.txtRespuestas de la Parte 3

Empaquete y envíe

Reúna todos los archivos en una carpeta, comprímala y genere una suma de verificación para que podamos confirmar que el archivo llegó íntegro.

HOST DE CAPTURA (LINUX)
tar -czf sitio-ejemplo_netstream-kit_20261105.tar.gz sitio-ejemplo/
sha256sum sitio-ejemplo_netstream-kit_20261105.tar.gz

Envíe el archivo comprimido y la línea de la suma de verificación al contacto de Illumio que le entregó este kit.

Comparta por su canal aprobado
La captura contiene las direcciones IP internas de sus servidores y equipos de red, y la salida de los comandos contiene nombres y direcciones de equipos. Envíe los archivos por el canal de intercambio de archivos que su organización apruebe para este tipo de datos. Los comandos filtrados de este kit no muestran contraseñas ni claves; revise los archivos antes de enviarlos si agregó la configuración completa.

Lista de verificación final

  • Archivo de captura — un archivo por switch, o uno con todos los switches, de al menos 15 minutos con plantillas, o de 40 minutos.
  • Salida de comandos — un archivo de texto por switch con los comandos de la Parte 2.
  • Cuestionario — respuestas para cada switch y las preguntas generales.
  • Horas — el valor date -u del host y el valor display clock de cada switch.
  • Paquete — archivo comprimido y suma de verificación enviados por el canal aprobado.
